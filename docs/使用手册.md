# FoxHubClaw 使用手册

给拿到安装包的人看。开发者搭环境见仓库根目录 `README.md`。

## 1. 桌面版怎么开

1. 解压分发包，不要只拷一个 EXE 而丢掉手册。
2. 双击 `FoxHubClaw.exe`。
3. 等几秒出现窗口，标题是 **FoxHubClaw**。
4. 左侧是：即时查询、定时任务、查询报告、设置。

关掉窗口即退出。本机数据写在 **EXE 同目录的 `data` 文件夹**（库文件和报告都在这里）。换电脑时把整个文件夹一起带走。

换新版本前先退出正在运行的 FoxHubClaw，再覆盖 EXE。

Windows 若提示「未知发布者」，选仍要运行。这是未签名桌面程序的常见提示，不是安装向导。

## 2. 第一次：填红狐 Key

查询前必须有 Key。

1. 打开 https://redfox.hk 登录，在账户里创建 API Key。
2. 软件左侧进 **设置**。
3. 把 Key 粘进「RedFox API Key」，点 **保存**。
4. 上方「当前 Key」应变成掩码，只露出末四位。

以后改 Key：再贴一条新的并保存。留空保存只改条数，不改 Key。

**不要把 Key 发给别人，不要写进报告，不要截图未掩码的设置页。** 管理员在网页版也看不到别人的明文 Key。

## 3. 即时查询

1. 打开 **即时查询**。
2. 输入关键词，或点一枚常用提示词自动填入。
3. 勾选 **帖子 / 作品**、**评论**，可只选一种，也可两种一起选。
4. 勾选平台。灰色平台表示当前勾选的类型它做不了；灰字是原因。
5. 点 **开始查询**。
6. 表格出结果。标题能点则打开原帖。上方有各平台条数。
7. 某平台没出数时，下面「部分平台未出结果」会写原因，例如暂不支持、接口成功但没解析到结果。

提示词可点 **自定义** 增删，或恢复默认。默认包括：人工智能、国货美妆、新能源汽车、夏季防晒、数码评测、减脂餐、考研备考、家居收纳、咖啡测评、亲子露营。

### 平台对照

| 平台 | 帖子 / 作品 | 评论 | 使用时注意 |
| --- | --- | --- | --- |
| 抖音 | 能 | 不能 | 评论接口未对关键词开放 |
| 小红书 | 能 | 不能 | 同上 |
| 公众号 | 能 | 不能 | 同上 |
| B站 | 能 | 能 | 先搜作品，再拉评论较多的视频；评论接口要轮询，常见要等约半分钟 |
| 今日头条 | 能 | 不能 | 接口经常只回十几条以内，点赞可能为空 |
| 快手 | 能 | 能 | 先搜作品，再拉热门作品评论 |
| 微博 | 能 | 能 | 先搜博文，再拉热门博文评论 |
| TikTok | 不能 | 不能 | 红狐目前只有用户搜索 |

评论走「先搜作品，再按下钻条数取前面几条去拉评论」。下钻条数在设置里，默认 3。B 站会跳过显示 0 评论的作品，避免空等。

同时勾选帖子和评论时：有帖子能力的平台仍可勾选；没有评论能力的平台会带说明，但帖子照查。

## 4. 定时任务

1. 打开 **定时任务**。
2. 填关键词，选每天或每周。
3. 点 **创建任务**。任务按当前默认：已开通帖子能力的平台，查帖子 / 作品。
4. 列表里可 **切换** 开启或暂停。

EXE 或网页服务在跑时，大约每分钟看一次有没有到期任务。关掉软件，到期任务要等下次打开后再跑。

## 5. 查询报告

即时查询和定时任务成功后，都会在 **查询报告** 留一条。

- **HTML**：浏览器打开，方便扫一眼。
- **Excel**：表格下载。
- **PDF**：打印或归档。中文用系统字体渲染。

桌面版点 Excel / PDF 会走系统下载，不要关太快。本页下方「最近运行」显示状态和条数。

报告不发邮件，只存在本机（桌面版）或服务器数据目录（网页版）。

## 6. 设置项

| 项 | 默认 | 作用 |
| --- | --- | --- |
| RedFox API Key | 空 | 调用红狐 |
| 每平台条数 | 20 | 每个平台最多取多少条帖子 |
| 评论下钻条数 | 3 | 每个平台拿多少条热门作品去拉评论 |

条数越大，越慢，也越耗红狐额度。B 站评论尤其明显。

## 7. 网页版（给部署的人）

桌面版不用注册。网页版要账号。

1. 打开站点，**创建账号**。第一个注册的人是管理员。
2. 之后用邮箱或用户名登录。
3. 每人自己的 Key、任务、报告互相隔离。
4. 管理员在 **后台管理** 启用或停用账号，看不到别人的 Key。

本地开发默认 http://127.0.0.1:8787 。命令见 `README.md`。

## 8. 常见问题

**窗口是空白的，或根本打不开。**  
确认是 Windows 10/11。Win10 安装 Microsoft Edge WebView2 Runtime 后再开。不要用「以管理员运行」乱改工作目录，以免 `data` 写到别处。

**提示 Key 无效或已失效。**  
回设置重新粘贴。确认红狐控制台里这条 Key 还在、额度没用完。

**选了很多平台，有的是空的。**  
看「部分平台未出结果」。灰平台本来就不会查。头条条数少是接口本身的情况。

**B 站评论很慢或只有很少几条。**  
接口要排队取结果；综合结果里很多视频本身没有评论。软件会优先拉有评论的作品。没有可拉的就空着，不会一直转圈到失败。

**Excel / PDF 点了没反应。**  
用当前分发包里的 EXE。旧版窗口默认禁下载。HTML 能开、表格不能下，多半是旧包。

**换了新 EXE，以前的查询没了。**  
数据在旧 EXE 旁边的 `data`。把 `data` 拷到新 EXE 同目录。

**8787 被占用。**  
桌面版会自动换空闲端口，不必关别的程序。网页版要自己改端口或停掉占用进程。

## 9. 安全

- Key 存在本机 SQLite，按机器密钥加密。设置页只显示末四位。
- 不要把 `data` 文件夹发到公开网盘。
- 仓库和分发包都不带你的 Key，也不带现成 EXE（EXE 需自行打包）。
