# FoxHubClaw

红狐关键词查询台。把你自己的 [RedFoxHub](https://redfox.hk) API Key 贴进软件，按关键词检索各平台帖子和评论，立刻出结果，也可按天或按周自动跑，报告在软件里下载 Excel、HTML、PDF。

软件名是 **FoxHubClaw**。界面默认中文。查询走红狐接口，费用和额度以红狐账户为准。

## 适合谁

内部值班、选题调研、舆情扫一眼。发给同事双击就能用，不必先装 Python。

## 两种用法

| 版本 | 给谁 | 怎么进 |
| --- | --- | --- |
| 桌面 EXE | 个人或内部分发 | 双击即用，不用注册 |
| 网页版 | 多人共用一台服务 | 邮箱或用户名加密码；第一个注册的人是管理员 |

## 现在能查什么

| 平台 | 帖子 / 作品 | 评论 |
| --- | --- | --- |
| 抖音 | 能 | 不能（红狐没有关键词评论接口） |
| 小红书 | 能 | 不能 |
| 公众号 | 能 | 不能 |
| B站 | 能 | 能（先搜作品再拉评论，可能要等半分钟） |
| 今日头条 | 能（条数往往偏少） | 不能 |
| 快手 | 能 | 能 |
| 微博 | 能 | 能 |
| TikTok | 不能 | 不能 |

## 分发包里放什么

仓库不收录 EXE。对外发包时打成一个文件夹即可：

```
FoxHubClaw/
  FoxHubClaw.exe
  项目简介.md
  使用手册.md
```

EXE 在打包机上生成：`backend/dist/FoxHubClaw.exe`。手册从本目录复制。

## 对方要准备什么

1. Windows 10 或 11。Win10 若窗口打不开，先装 [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)。
2. 自己的红狐 API Key：https://redfox.hk
3. 打开软件 → **设置** → 粘贴 Key → 保存。界面只显示末四位。
